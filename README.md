## 📊 Data Projects

**Flight Delay Big Data Analysis** · [Code](https://github.com/ZenBen5173/IST3134-Flight-Delay-BigData)
Analysed **62M US flight records (2015 to 2024)** to find the worst airports, routes, carriers and times, and how delay causes shifted over the decade. Ran the same analysis in **pandas on one machine vs PySpark on a 3-node AWS EMR cluster**: pandas needed 38.4 GB of memory and 479s, while Spark finished in **250s**.

**MongoDB NoSQL Injection: Vulnerable vs Hardened** · [Code](https://github.com/ZenBen5173/mongo_nosql_injection)
Built two Express + MongoDB apps with the same endpoints: one open to **NoSQL operator injection** (e.g. logging in as admin without the password), one hardened with input validation. Includes the full set of attack payloads to compare both.

**E-Commerce Late-Delivery Prediction**
Cleaned and validated **~96K orders**, benchmarked 5 models to predict late deliveries, and built an interactive dashboard.

**Obesity Prediction from Lifestyle Habits**
Python pipeline (pandas, scikit-learn) on 2,111 records across 7 classes. Benchmarked Logistic Regression, SVM and Random Forest (best). ANOVA and Chi-Square tests found **water and vegetable intake** as the top predictors.
